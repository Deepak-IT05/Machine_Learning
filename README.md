# Machine Learning Practice with Python

Welcome to my Machine Learning Practice repository! 🚀

This repository contains my hands-on practice programs and experiments using Python, scikit-learn and Jupyter Notebook. I am building my Machine Learning knowledge step by step from fundamental algorithms to model optimization and evaluation.

## 📂 Repository Structure

### 1. Regression
Practice programs for predicting continuous numerical values.
- Linear Regression
- Multiple Linear Regression
- Support Vector Regression (SVR)

### 2. Classification
Practice programs for predicting categories or class labels.
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Support Vector Machine (SVM)

### 3. Clustering
Practice programs for grouping similar data points.
- K-Means Clustering
- Agglomerative Clustering

### 4. GridSearchCV
Practice programs for hyperparameter tuning and model optimization.
- GridSearchCV for Regression
- GridSearchCV for Classification

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 🎯 Learning Objectives
- Understand the fundamentals of Machine Learning algorithms.
- Practise data preprocessing and model training.
- Evaluate model performance using suitable metrics.
- Learn cross-validation and hyperparameter tuning.
- Improve practical Python and Machine Learning skills.
- Progress toward Deep Learning and Generative AI.

## ▶️ How to Run
1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required libraries:
   `pip install numpy pandas matplotlib seaborn scikit-learn jupyter`
4. Open Jupyter Notebook and run the `.ipynb` files.
